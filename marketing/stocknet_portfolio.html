Project Overview
StockNet is a fully custom, end-to-end IoT inventory management system built for an electronics manufacturer who needed real-time bin-level stock visibility across their warehouse floor — without spreadsheets, without a SaaS subscription, and without expensive RFID infrastructure.

The system spans every layer of the stack: custom ESP32-S3 hardware with OLED display, physical buttons, and battery monitoring; a Python Flask + PostgreSQL backend with fleet management, BOM-aware inventory tracking, tiered alerting, and production order planning; and a dark-themed web dashboard with live charts and remote device configuration — all self-hosted on the client's local network.

Technical Challenges Solved
ESP32-S3 ADC Non-Linearity
Battery voltage readings were triggering false low-battery alerts from ADC noise near the rails. Solved with rolling-average multi-sample reads and correct attenuation settings — accurate to ±50 mV.
BLE Command Replay on Reconnect
Devices reconnecting after WiFi outages needed to replay only unacknowledged commands. Designed a per-device pending → acked / failed lifecycle so reconnects always resume cleanly.
Concurrent BOM Deduction Races
Multiple assembly counters posting simultaneously could race against the BOM deduction logic. Moved all upsert + deduction into a single PostgreSQL transaction per POST, eliminating the race without application locks.
Full Zephyr RTOS Port
Ported the entire Arduino sketch to Zephyr for OTA-upgrade support — remapping every peripheral to the Zephyr device tree. Delivered a line-by-line port guide for future maintainers.
